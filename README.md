## 各模块用途说明

### 1) `douyin-scripts`
用于沉淀抖音短视频脚本：
- 选题库（转行、考证、就业、学习体验）
- 口播脚本模板（30s / 60s）
- 评论区引导话术
- 直播开场与转化话术

### 2) `xiaohongshu-content`
用于小红书图文内容：
- 爆款标题模板（真实经历、避坑、费用透明）
- 图文结构模板（痛点-过程-结果-行动）
- 关键词与标签管理
- 私信引流话术

### 3) `wechat-sales`
用于微信销售转化：
- 首次加微欢迎语
- 需求诊断提问清单
- 报名转化 SOP（试听→答疑→促单）
- 异议处理（价格、时间、通过率、就业）

### 4) `enrollment-sop`
用于招生执行标准化：
- 渠道分工与每日任务
- 线索跟进节奏（D1/D3/D7）
- 试听课流程
- 报名与缴费流程

### 5) `competitor-analysis`
用于竞品与同城机构分析：
- 同城账号监测表
- 价格与课程结构对比
- 内容策略差异分析
- 可复制动作清单

### 6) `daily-review`
用于每日复盘：
- 内容发布复盘
- 咨询数据复盘
- 转化漏斗复盘
- 次日改进动作

### 7) `lead-management`
用于线索管理与数据闭环：
- 线索台账模板（来源、阶段、意向分）
- 跟进记录模板
- 月度目标看板（10 人报名拆解）
- 渠道 ROI 简易统计
